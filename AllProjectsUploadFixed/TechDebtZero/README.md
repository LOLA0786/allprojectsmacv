# 🧠 TechDebtZero

**AI-powered Technical Debt Analyzer & Refactor Assistant**

### 🚀 Features
- Detects code smells (complexity, duplication, TODOs, etc.)
- Computes Technical Debt Score
- Auto-suggests refactors using AI
- Generates Markdown reports
- Works with CI/CD & GitHub Actions
